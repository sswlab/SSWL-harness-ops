👋 **논문 번역/분석 (Paper Mate) 하네스**에 오신 걸 환영합니다.

영어 학술 논문을 **완전히 한국어로 번역**하고, 수식은 LaTeX → 한글 PDF로 컴파일하며, 그림은 AI가 직접 보고 분석하고, 참고문헌은 중요도별로 분류합니다. 번역 후에는 자유롭게 **Q&A**도 가능합니다.

---

### 📋 입력 — 셋 중 한 가지 방식

| 방식 | 입력 예시 |
|---|---|
| **DOI** | `이 논문 읽어줘: 10.1038/s41586-021-03854-z` |
| **제목** | `"Attention Is All You Need" 논문 번역해줘` |
| **PDF 파일 첨부** | 채팅창에 PDF를 드래그&드롭 후 `이 논문 읽어줘` |

---

### 💬 빠른 예시

```
이 논문 읽어줘: 10.3847/1538-4357/ac1f0d
```

```
"Magnetic field measurements of active region NOAA 12673" 논문 번역해줘.
```
