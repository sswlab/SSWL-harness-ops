👋 **TeX 에디터 하네스**에 오신 걸 환영합니다.

LaTeX 원고(`.tex`)를 입력하면, **컴파일 → 시각·문법 검토 → 수정된 `.tex` 출력**까지 자동으로 수행합니다. GPT Prism과 유사한 역할을 로컬 에이전트 팀으로 처리합니다.

> ⚠ 과학적 내용은 건드리지 않습니다 (영문 문법·오타·시각 문제만 수정).

---

### 📋 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| **① 루트 `.tex` 파일** | 컴파일 진입점 | `/home/youn_j/papers/my_paper/main.tex` |
| **② 작업 경로** | 컴파일 중간물·리포트·수정본 저장 | `/home/youn_j/papers/my_paper/_tex-editor/` |

> 입력 `.tex`이 있는 디렉토리의 보조 파일(그림, `.bib`, 클래스/스타일)은 자동으로 같이 읽습니다.

---

### 🔍 검토 항목

| 카테고리 | 예시 |
|---|---|
| **컴파일** | undefined refs, missing figures, 에러·경고 |
| **시각** | 표 잘림, 그림 마진 벗어남, 캡션 분리, 페이지 경계 이상, 수식 줄바꿈 깨짐 |
| **문법** | 영문 문법 오류, 오탈자 (내용은 건드리지 않음) |

---

### 💬 그대로 복사해서 쓸 수 있는 프롬프트 템플릿

```
이 tex 파일 편집해줘: [/main.tex/경로]
작업 경로: [/저장/경로]
```

#### 실제 예시

```
이 tex 파일 편집해줘: /home/youn_j/papers/my_paper/main.tex

```
