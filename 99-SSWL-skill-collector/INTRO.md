👋 **SSWL 스킬 수집기 하네스**에 오신 걸 환영합니다.

흩어져 있는 연구실 코드를 모아 **분석 → 분류 → 모듈화 → 스킬 패키징**까지 수행하여, 다음에 다시 짜지 않아도 되는 재사용 가능한 자산으로 만듭니다.

---

### 📥 코드 넣는 방법 (둘 중 하나)

| 방법 | 설명 |
|---|---|
| **A. 로컬 inbox 사용** | `99-SSWL-skill-collector/_workspace/inbox/`에 코드 복사 (정리 안 된 상태 OK) |
| **B. 외부 경로 지정** | 코드가 있는 디렉토리 경로를 알려주기 |
| **C. 원격 서버 수집** | SSH 정보만 주면 `remote-collector`가 자동 수집·선별 |

---

### 📋 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| **① 코드 위치** | inbox 사용 시 생략 가능 | `/home/youn_j/old-scripts/stix/` |
| **② 변환 목적** | 왜 스킬화하는지 | `신입생 공용 도구로 만들기` |
| **③ 변환 모드** | 아래 4가지 중 선택 | `전체 변환` |
| **④ 작업 경로** | 인벤토리·분류·모듈·스킬 저장 위치 | `/home/youn_j/skills-workspace/` |

### 🎯 변환 모드

| 모드 | 적합한 경우 |
|---|---|
| **전체 변환 (Full Scan)** | 처음으로 코드를 정리할 때 |
| **추가 수집 (Incremental)** | 1차 정리 이후 새 코드가 생겼을 때 |
| **단일 변환 (Targeted)** | 변환 대상이 명확할 때 |
| **원격 수집 + 전체 변환** | 다른 서버에 코드가 흩어져 있을 때 |

---

### 💬 그대로 복사해서 쓸 수 있는 프롬프트 템플릿

```
[코드 위치 또는 inbox] 코드 정리해서 스킬로 만들어줘.

목적: [왜 스킬화하는지]
모드: [전체 / 추가 / 단일 / 원격]
작업 경로: [/저장/경로]
```

#### 실제 예시 — 로컬 inbox

```
inbox에 넣은 STIX 분석 코드들 정리해서 스킬로 만들어줘.

목적: 연구실 신입생이 바로 사용할 수 있는 공용 도구로 만들기
모드: 전체 변환
작업 경로: /home/youn_j/skill-collector-workspace
```

#### 실제 예시 — 원격 수집

```
163.180.171.99 서버의 코드를 수집해서 스킬화해줘.

SSH: youn_j@163.180.171.99
스캔 경로: /userhome/youn_j/lab-codes/
목적: 흩어진 레거시 코드 자산화
모드: 원격 수집 + 전체 변환
작업 경로: /home/youn_j/skill-collector-workspace
```

> 원격 수집은 SSH 키 인증 사전 설정 필요 (`ssh-copy-id user@host`).

준비되시면 위 템플릿대로 입력해 주세요. 🚀
