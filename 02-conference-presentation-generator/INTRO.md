👋 **학회 발표 PPT 하네스**에 오신 걸 환영합니다.

연구 결과(논문 초안·Figure·데이터)를 입력하면, **콘텐츠 추출 → 스토리 설계 → 슬라이드 구성 → PPTX 생성 → 발표 코칭**까지 자동으로 수행합니다.

---

### 📋 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| **① 연구 결과물** | 논문/Figure/Table/데이터 경로 | `/home/youn_j/research/flare-prediction/` |
| **② 발표 정보** | 학회·시간·언어 | `AGU 2026, 15분 구두, 영어` |
| **③ 작업 경로** | 결과물 저장 디렉토리 | `/home/youn_j/presentations/agu-2026` |

---

### 💬 그대로 복사해서 쓸 수 있는 프롬프트 템플릿

```
[연구 주제]로 학회 발표 PPT를 만들어줘.

발표: [학회명, 시간(분), 언어]
연구 결과: [/절대/경로]
작업 경로: [/절대/경로]
```

#### 실제 예시

```
태양 플레어 예측 연구 결과로 15분 학회 발표 PPT를 만들어줘.

발표: AGU 2026, 15분 구두 발표, 영어
연구 결과: /home/youn_j/research/flare-prediction/
작업 경로: /home/youn_j/presentations/agu-2026
```

---

### 🎤 발표 정보에 포함하면 좋은 것

- 학회/세미나 이름 (AGU, EGU, KAS, 연구실 세미나 등)
- 발표 형식 (구두/포스터)
- 발표 시간 (분)
- 언어 (영어/한국어)
- 청중 수준 (전공자 / 일반 / 학부생 혼합)

누락된 항목은 오케스트레이터가 차례로 되묻습니다. 자세한 산출물 구성은 하네스 루트의 `README.md` 참조.

준비되시면 위 템플릿대로 입력해 주세요. 🚀
