👋 **Symbolic Regression 하네스**에 오신 걸 환영합니다.

데이터와 과학적 질문을 제시하면, **데이터 진단 → SR 도구 자동 라우팅 → 병렬 실행 → SymPy 후처리 → Pareto/LaTeX 보고**까지 자동으로 수행합니다. 관측·시뮬레이션 데이터로부터 **해석 가능한 닫힌 형태의 수식**을 발견합니다.

---

### 📋 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| **① 데이터** | CSV/FITS/numpy 경로 | `/home/youn_j/data/solar_wind.csv` |
| **② 연구 질문** | 무엇을 찾고 싶은지 | `B와 v 사이 관계식을 찾아줘` |
| **③ 변수 의미·단위** | 물리 단위 (있으면 AI Feynman 활성화) | `X1=B (nT), X2=n (cm⁻³), y=v (km/s)` |
| **④ 제약·사전지식** *(선택)* | 알려진 조건 | `결과 양수, 단조 증가 예상` |
| **⑤ 작업 경로** | 결과 저장 디렉토리 | `/home/youn_j/experiments/sr-solar-wind` |

---

### 💬 그대로 복사해서 쓸 수 있는 프롬프트 템플릿

```
[데이터에서 찾고 싶은 관계]를 SR로 찾아줘.

데이터: [/절대/경로]
변수: [X1=... (단위), X2=... (단위), y=... (단위)]
제약: [선택]
경로: [/절대/경로]
```

#### 실제 예시

```
태양풍 데이터에서 속도-자기장 경험식을 찾아줘.

데이터: /home/youn_j/data/solar_wind.csv
변수: X1=B (nT), X2=n (cm⁻³), y=v (km/s)
제약: 결과는 양수, 단조 증가 예상
경로: /home/youn_j/experiments/sr-solar-wind
```
