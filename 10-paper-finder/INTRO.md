👋 **논문 탐색·우선순위화 (Paper Finder) 하네스**에 오신 걸 환영합니다.

주제를 던지면, **검색 전략 수립 → NASA ADS·arXiv·Semantic Scholar 병렬 검색 → 2D 병렬 분석 → 1논문 1카드 요약 → 우선순위 보고서(Markdown+PDF)**까지 자동으로 수행합니다.

> **"얕고 넓게 정찰"** 전용. 한 편을 깊게 번역·분석하려면 `04-paper-mate`로 넘기세요.

---

### 📋 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| **① 주제** | 자연어 또는 키워드 | `태양 코로나 가열 메커니즘` |
| **② 연도 범위** *(선택)* | 최근 N년 또는 절대 범위 | `2020-2025`, `최근 5년` |
| **③ 검색 규모** *(선택)* | 후보 논문 수 | `top 15` |
| **④ 다운로드 정책** | 검색 후 매번 묻습니다 | `all` / `top N` / `none` / `pick #3 #5` |

---

### 💬 그대로 복사해서 쓸 수 있는 프롬프트 템플릿

#### A. 자유 텍스트

```
[주제] 관련 최근 [N]년 논문 [상위 N편] 찾아줘.
```

#### B. 슬래시 명령

```
/paper-find [주제], [연도범위], top [N]
```

#### 실제 예시

```
태양 코로나의 가열 메커니즘 관련 최근 5년 논문 찾아줘.
```

```
/paper-find solar coronal heating mechanism, 2020-2025, top 15
```
