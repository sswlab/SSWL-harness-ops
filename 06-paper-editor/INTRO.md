👋 **논문 편집 (Paper Editor) 하네스**에 오신 걸 환영합니다.

기존 논문(`.tex`/`.pdf`/`.md`)을 입력하면, 원하는 작업(문법 교정 / 팩트체크 / 모의 피어리뷰 / 구조 개선)을 수행합니다. **원본 파일은 수정하지 않으며**, 교정본과 리포트를 별도 파일로 생성합니다.

> ⚠ 이 하네스는 **기존 논문 품질 개선** 전용입니다. 새 논문을 처음부터 쓰려면 `03-paper-writer`를 사용하세요.

---

### 📋 입력 항목

| 항목 | 설명 | 예시 |
|---|---|---|
| **① 논문 파일** | 편집 대상 경로 | `/home/youn_j/papers/draft.tex` |
| **② 작업 모드** | 아래 4가지 중 1개 이상 (복수 가능) | `문법 교정 + 모의 리뷰` |
| **③ 보조 자료** *(선택)* | 팩트체크용 코드/데이터/Figure | `/home/youn_j/research/results/` |
| **④ 작업 경로** | 결과물 저장 디렉토리 | `/home/youn_j/papers/draft-review/` |

### 🎯 작업 모드

| 모드 | 설명 |
|---|---|
| **문법·표현 교정** | 영문 문법, 학술 표현, 용어 일관성, 오타 |
| **팩트체크** | 한 문장씩 검증, 출처 없는 주장에 레퍼런스 추천 |
| **모의 리뷰** | 리뷰어가 팩트체크 + 방법론/해석 평가 (1회) |
| **구조 개선 제안** | 섹션 구성, 논리 흐름, Figure/Table 배치 |

---

### 💬 그대로 복사해서 쓸 수 있는 프롬프트 템플릿

```
이 논문 [모드] 해줘: [/논문/경로]
작업 경로: [/저장/경로]
```

#### 실제 예시

```
이 논문 문법 교정 + 모의 리뷰 해줘: /home/youn_j/papers/draft.tex
작업 경로: /home/youn_j/papers/draft-review/
```

```
이 논문 리뷰해줘: /home/youn_j/papers/my_paper.pdf
```
→ 모의 리뷰 모드로 진입, 작업 경로만 되묻습니다.

준비되시면 위 템플릿대로 입력해 주세요. 🚀
